raccourci.

French for “shortcut”.

Fractions, percentages, words, and arithmetic.
A small TypeScript library with no runtime dependencies.

Try it

Result 133.33333333333331 Full numeric precision. Clear the reference amount for arithmetic.

Install

Download the package ↓

Download the built package, then run this in the folder containing it. This release is not on npm yet.

npm install ./raccourci-0.1.0.tgz

Use the same function in vanilla TypeScript, React, or Node.js:

import { resolveAmount } from 'raccourci';

resolveAmount('half + 10', 200); // 110
resolveAmount('100 - (5*3)');    // 85

Or use a script tag

No build step. Mark a text input to convert its value on blur or Enter.

<script src="https://fieu.github.io/raccourci/raccourci.umd.js"></script>
<input type="text" data-resolve-amount="200">

Typing 2/3 becomes 133.3333. Optional attributes: data-resolve-locale, data-resolve-precision, and data-resolve-rounding.

Invalid expressions return null. A standalone fraction is a share of the reference; division inside a larger expression follows normal arithmetic. Results use JavaScript numbers and are not clamped.
